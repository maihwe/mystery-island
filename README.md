# Mystery Island — The Lost Lighthouse

A beginner-friendly, text-based Python adventure. Explore five locations,
collect a rope and a lantern, cross the broken bridge, light the lighthouse
beacon, and survive on 5 units of energy.

## Prerequisites
- Python 3.9+ (tested on 3.11)
- No external packages required (standard library only)

## How to run
```bash
python main.py
